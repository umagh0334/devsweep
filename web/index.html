Safe by construction

A delete tool you can actually trust pointing at your home folder.

DevSweep never guesses. It only touches paths it explicitly knows are caches, and it shows you everything before a single byte moves.

Whitelist-only

Every path and command is explicitly listed. Anything DevSweep doesn't recognize, it leaves untouched — your source and projects are never in scope.

Dry-run by default

Run it and you see exactly what would be freed. Deletion only happens when you confirm with --yes — or one click in the app.

Native cleanup first

Where a tool has its own cleaner — brew cleanup, npm cache clean, docker prune — DevSweep runs that, and only falls back to rm when there's none.

The engine

A bash core you can read in one sitting.

The GUI is a thin shell over a transparent CLI. Same scan, same safety, scriptable in CI — and the app speaks 12 languages on top.

Built for daily use

More than a delete button.

Everything you'd want before, during, and after a sweep — so cleanup becomes something you set once and stop thinking about.

Risk-tiered badges

A traffic-light read on every cache before you commit — so you know what's free vs. what costs a re-download.

SafeMid costCautionHeavy

Scheduled auto-clean

Daily, weekly, or monthly via launchd. Stateful tools like Docker stay out of the automatic pass on purpose.

Done-notifications

A system notification when a sweep finishes, with how much it freed — manual or scheduled, you always know.

Protect list

Pin caches you never want swept. Protected items are skipped everywhere — manual, scheduled, and all.

Age filter

Only clear what's gone stale — keep caches younger than the window you set, sweep everything older.
